# Ponte

Use o seu PC no celular ou em outro PC, de qualquer lugar.

Baixe a versão mais nova em [Releases](https://github.com/oliveiraski/ponte-downloads/releases/latest):

- **Ponte-Setup.exe**: instalador para Windows
- **stream-app.apk**: app para Android

Para entrar, use a sua conta do [ZeroTier](https://my.zerotier.com): escolha uma rede sua ou crie uma nova pelo próprio app.
